# 谈判术 
哈佛经典谈判术: 优秀的谈判在于谈判前做足准备,充分掌握信息,谈判时控制情绪和表达,谈判结果应该尽量创造共同价值做大蛋糕,符合道德并且可以加强人际关系。

## 1. 谈判前：准备阶段
### 1.1 评估自己的最佳备选方案（BATNA）
1. 列出谈判不成时你所有的备选路径。
2. 逐一估算每个备选方案的价值。
3. 选出其中最好的一个，这就是你的 BATNA。
4. **BATNA 不是你认为公平的价格或希望达到的目标。** 它是谈判破裂后你必须面对的现实。如果你的期望脱离现实，你会在谈判中要么过于强硬导致破裂，要么过于软弱做出不必要的让步。

### 1.2 计算自己的底线
1. 底线通常围绕 BATNA 确定，可根据风险偏好微调。
2. 底线就是无差别点：对方出价刚好等于它时，接受和拒绝对你来说没有区别。低于这个值你直接走人更划算，高于这个值你至少不亏。
3. 不要把底线和期望目标混为一谈，否则你会混淆“必须守住”和“争取达到”这两件事。

### 1.3 评估对方的最佳备选方案（最关键的一步）
1. 对方谈判不成的替代方案是什么？（他会转向谁？）
2. 那个替代方案对他有多好？
3. 对方的最佳备选方案越差，你的谈判空间就越大——因为对方的弱势才是你争取价值的真正空间。

### 1.4 计算对方的底线
1. 站在对方的位置，分析他能承受的最差结果。
2. 需要了解对方的行业处境、时间压力、内部决策规则和隐性限制（如预算上限、过往承诺）。
3. 信息不足时先列出合理的假设，后续验证。否则你会基于错误的前提推进谈判，要么报价太低错失价值，要么报价太高激怒对方。

### 1.5 确定协议区间
协议区间就是你的底线到对方底线之间的范围，这个范围内任何结果理论上双方都能接受。你的目标不是“达成协议”，而是争取到尽可能接近对方底线的结果。

### 1.6 明确自己的多个利益点
1. 不要只盯价格。列出所有可谈的议题：时间、付款条件、附加服务、质保、未来合作等。
2. 给每个议题设定权重（可以用金额换算）。有了评分系统，你才能客观评估组合提案，而不是在单一维度上死磕。

### 1.7 列出所有假设并逐一质疑
1. 把谈判前的大量预设写下来（如“对方肯定不同意”“商业开发不可能”）。
2. 逐个反问：如果这个假设是错的，我的计划该怎么调整？提前发现漏洞比临时补救安全得多，而且假设往往带有自我中心的偏见。


## 2. 谈判开场：报价与锚定
### 2.1 判断是否应该首先报价
1. 如果你对协议区间有足够把握，就抢先报价。第一个数字会形成“锚”，把对方预期拉向你的方向。
2. 如果信息不足，就让对方先报。避免自己报得太低或太离谱，否则你会白白扔掉本可争取到的价值。
3. **锚定效应非常强大**，即使经验丰富的对手也很难免疫。人类判断不确定数值时，会不自觉地被第一个出现的数字吸引。

### 2.2 设计一个高质量的首轮报价
1. 报价要落在协议区间之外，给自己留退让空间。否则你一开口就放弃了报价到对方底线之间的那部分价值。
2. 报价必须附有充分的理由——不一定要绝对正确，但要听起来合理有说服力。理由越充分锚就越稳。
3. 设定一个很高但可行的目标价。研究证明期望越高的谈判者最终结果越好，因为目标会引导你的行动和坚持程度。
4. 考虑双方关系和行业惯例。报价太激进可能损害长期合作，要在短期利益和长期信誉之间平衡。

### 2.3 当对方先报价时，不要被牵着走
1. 忽略对方的锚，不要围绕他的数字争论，直接转到其他议题上。争论对方的数字只会强化它在双方心中的影响。
2. 区分有效信息与“忽悠”。有效信息能帮你修正协议区间的估计，而忽悠只会让你偏离理性。
3. 避免追问他为什么报这个价。讨论越多锚的影响越大，他会用各种理由来合理化那个数字。
4. 用一个同样极端的还价来对冲，再提议双方一起向中间靠拢。能中和对方锚的影响，同时展现合作姿态。
5. 给对方时间和台阶，让他能“回去重新核算”。他不可能马上大幅降价，因为要保全面子。否则他会因为面子问题而拒绝让步，即使内心知道可以更低。

### 2.4 警惕对方的信息优势（胜利者的诅咒）
1. 如果对方手里有你不知道的关键信息（如勘探结果、产品质量），而你的报价被对方迅速接受，不一定是你谈得好——更可能是你出价过高了。
2. 报价前想象一下“如果对方马上接受我的报价，我会是什么感觉？”如果觉得不安，说明你可能忽略了对方的信息优势。
3. 对策：用条件式出价或权变协议，把付款与未来结果挂钩，避免为信息劣势买单。


## 3. 谈判中：讨价还价与信息博弈
### 3.1 讨价还价的核心策略
1. 聚焦对方的底线和最佳备选方案，而不是只盯着自己的。对方的困境才是你争取价值的空间。
2. 不要单方面让步。让步必须是对等的，否则对方会认为你还可以继续退。
3. 不要害怕沉默。对方没回应时，不要自己先开口。沉默会让对方先沉不住气，先开口的人往往会做出让步。
4. 让步时必须贴上标签，让对方知道你让步是有代价的（例如“我这次让步是为了回应你上次的调整”）。否则对方会认为理所当然，不会回报。
5. 明确定义对等，告诉对方你期待什么具体回应。模糊的期待容易被忽略，明确的要求才能推动对方行动。
6. 可以使用条件让步，如“如果你愿意提前发货，我可以接受更高的价格”。能把让步和对方的具体行为绑定。但不能滥用，否则对方觉得你缺乏合作诚意。
7. 注意让步幅度的缩小信号：对方每次让步越来越小，通常意味着接近底线了，因为越靠近底线调整空间越少。但要警惕这可能是假象——他可能先大步让步让你放松，再小步假装到底，其实还有空间。

### 3.2 创造价值
1. 警惕零和偏误。不要默认每个议题都是你赢我就输。大多数谈判有多个议题，可以通过互换让双方都更好。
2. 互换的核心：找出对方看重但你不太看重的议题，用来换取你看重但对方不太看重的议题。双方都能用低成本的让步换取高价值的回报。
3. 同时谈多个议题，不要逐议题谈。逐议题谈会消灭互换的可能，组合提案才能创造价值。
4. 价格谈不拢时尝试引入新议题，如交货时间、付款方式、售后服务或未来合作。议题越多，找到双方高优先级事项的机会越大。
5. 当双方对未来预期不同时，使用权变协议把赌注押在各自的判断上。避免现在就争论谁对谁错，等结果明朗时自然分晓。**权变协议必须对双方的激励方向一致**，否则对方可能有动机把事情搞砸（如故意降低销量来赢得赌约）。
6. 注意寄生式价值创造：并非所有的“价值创造”都是道德的。有些协议表面让谈判双方获益，代价却由未到场的人承担（如制药公司合谋提价损害消费者）。如果协议会影响第三方，需要审视其公平性。

### 3.3 侦探式谈判
1. 不要只问“是什么”，要问“为什么”。诉求背后的利益点才是你能真正满足的需求。
2. 努力调和利益点，不要在诉求上纠缠。诉求往往是表面的、对立的，利益点才是潜在的、可以兼容的。
3. 求同存异。即使是对手，也可能在某些维度上合作（如 2000 年戈尔和纳德支持者互换选票，因为各自的利益点不同但互补）。
4. 把对方的要求当作机会。对方有需求，而需求就是你可以利用的信息。
5. 不要把对方的问题当成“对方的问题”。对方受限制，最终也会伤害到你，比如供应商运输成本高会导致你承担更高价格。
6. 被拒绝后不要结束谈判，要问“为什么不”。对方拒绝后给你的理由往往是关键信息，你之前可能完全没想到。
7. 区分推销和谈判。推销是告诉对方你有多好，谈判是了解对方想要什么。倾听比说服更重要。

### 3.4 从口风紧的对方那里获取信息
1. 建立信任。从安全的信息开始主动分享，逐步深入。否则对方没有理由信任你，就不会分享关键信息。
2. 主动提问，尤其当你感到惊讶或有疑虑时。不问就永远得不到答案。
3. 利用互惠原则。先提供一些自己的信息，对方往往愿意开口。人们本能地觉得有义务回报别人分享信息的善意。
4. 同时谈多个议题，观察对方在哪个议题上最坚持。那就是他的优先级所在，因为人在真正看重的议题上会花更多时间争论。
5. 同时给出多个提案。对你价值相同但侧重点不同的提案，看对方偏好哪个，就能判断他的真实优先级。他对哪个议题敏感，就会选择对其有利的提案。

### 3.5 拓展视野，避免盲点（有限意识）
1. 谈判时很容易只盯着眼前的报价和议题，忽略那些不在现场的人（如竞争对手、决策者背后的利益集团、未来才会出现的利益相关方）。
2. 主动问自己：这个协议会影响谁？谁不在谈判桌上但会被波及？竞争对手会作何反应？现在的妥协是否会变成未来的先例？
3. 在重要谈判前分配角色，让团队成员专门负责监控这些“盲点”信息，定期开会更新。


## 4. 谈判中：影响力策略
### 4.1 8 个被验证有效的说服策略
1. 强调损失而不是收益。“不接受会失去 X”比“接受能得到 X”更有力。损失厌恶是本能，人们对损失的敏感度远高于对收益的期待。但不能滥用，否则会营造过度负面的氛围。
2. 细分收益，整合损失。好消息分次给，坏消息一次全部说清。多次好消息的快乐总和大于一次大好消息；而一次承受全部损失比分次承受的痛苦要小。
3. “摔门”法：先提一个很高、很可能会被拒的要求，被拒后马上提出真正的要求，对方会觉得你在让步。对比效应让他觉得第二个要求合理得多，互惠本能也让他觉得该回应你的“让步”。两步之间要快，否则对比效应会减弱。
4. “蹬门槛”法：先提一个很小的要求，等接受后再逐步升级。人们一旦答应了小请求，就会在心里把自己定位为“愿意帮忙的人”，后续大请求更容易被接受。但第二步不能太快，否则对方觉得被算计。
5. 利用合理化的力量：提出请求时加上“因为……”，即使理由不充分也更容易被接受。人们天生觉得有理由的请求更合理。最好有数据支持，能增强可信度。
6. 利用认可的力量：暗示你的请求已得到很多人的认可。人们有从众心理，看到别人也在做，会觉得这事更安全，比如“电话繁忙请稍后再拨”暗示很多人都在打。
7. 作象征性的单方面让步。很小的善意（如调整见面时间、带杯咖啡）能换来对方更大的回报。互惠本能会驱动对方回报。
8. 利用合适的参照点来合理化提案。同样一笔折扣，放在贵的东西旁边显得微不足道，放在便宜的东西旁边显得很有诚意。人们判断价值时依赖参照框架，而非绝对数值。


## 5. 谈判中：应对谎言与欺骗
### 5.1 先发制人，防止被欺骗
1. 表现出准备充分的样子。对方觉得你不好骗，撒谎的风险高。
2. 展示你获取信息的能力。让对方知道撒谎有暴露的可能。
3. 间接问一些没有威胁性的问题，从侧面推断你需要的信息。直接问敏感问题容易引发谎言。
4. 主动表达诚意，打破“别人都撒谎所以我也不得不撒谎”的恶性循环。你展示诚实，对方可能以诚相报。

### 5.2 测谎的策略
1. 信息收集多元化，从多个渠道交叉验证。单一信息容易被伪造，多个来源一致时可信度高。
2. 设套：问一个你已经知道答案的问题。如果对方撒谎，你就直接抓住证据。
3. 多方验证：问多个相关问题。谎言很难在多个角度都保持前后一致。
4. 注意“没有回答你问题”的回应。对方可能在误导你，但没有直接撒谎。这样他会觉得自己没有道德负担，但实际在回避核心问题。
5. 对赌权变协议。如果对方坚信自己的判断，他应该愿意接受赌约。如果他虚张声势就会拒绝，因为权变协议会让他付出代价。

### 5.3 发现对方撒谎后怎么办
1. 先确认对方是否故意撒谎。可能只是信息有误或文化差异，直接指责会让冲突升级。
2. 决定是继续谈判还是离开。如果谎言严重且对方毫无悔意，不如终止谈判。
3. 如果选择继续，让对方知道你发现了，但一定要给他台阶下。例如说：“也许您的数据过时了，接下来我们在事实上更仔细一些。”给他挽回面子的机会，才能继续合作。

### 5.4 如何避免自己撒谎
1. 提前考虑声誉和关系的长期成本。否则短期利益会诱惑你犯错。
2. 准备好回答困难问题的脚本。这样你就不需要用谎言来应急。
3. 不要在高压下回答问题。条件不允许时可以要求推迟回答。时间压力会让人本能地选择谎言这个捷径。
4. 有些问题可以拒绝回答，或转移话题。拒绝比撒谎更诚实，也不会带来后续麻烦。
5. 主动要求回答另一个相关的问题来替代。
6. 改变现状，消除诱使撒谎的束缚。提前收集信息、改善处境，你就没编造的必要了。


## 6. 谈判中：劣势时如何谈判
### 6.1 没有权力时的策略
1. 不要暴露自己处于劣势。如果对方不知道你的 BATNA 很差，你就还有谈判空间。
2. 利用对方的弱点来克服你的弱点。你的 BATNA 差，但他的 BATNA 可能也差，协议区间反而会变大。
3. 识别并利用你的独特价值贡献。可以提交多个提案（低价基础款 vs 高价高配款），看对方更倾向哪个。帮你探测对方的真实需求。
4. 可采取分阶段策略：把价格定到刚好能进入下一轮，然后在多议题谈判中争取价值；如果输掉竞标，仍可联系客户提出组合方案；不在竞标时也与客户保持联系，让对方在非压力环境下了解你的价值。
5. 如果劣势非常明显，完全放弃权力，请求对方的直接帮助。如先接受工作，然后请对方重新考虑薪酬。当你不攻击对方时，对方更容易放下防御。
6. 根据整体谈判组合制定策略。即使失去一部分生意，如果能谈成更高利润率，总体上反而更赚。

### 6.2 打破权力格局的策略
1. 与其他劣势方结盟。联合起来削弱对方的最佳备选方案，如员工组建工会。
2. 专注于创造价值，提醒对方：如果把你逼出局，他们也会失去你创造的价值。对方可能也需要你生存下去。
3. 了解并攻击对方的权力来源。搞清楚对方为什么能欺负你，然后破坏那个来源。例如“示威捐款”让示威者的数量成了诊所的收入来源，从而让示威者失去动力。


## 7. 谈判中：面对非理性、愤怒、威胁和面子问题
### 7.1 应对非理性
1. 大多数“非理性”背后有理性原因。先检查三种可能：
   - 对方信息不完整。帮他了解情况，问题往往就解决了。
   - 对方有隐藏的限制。如权限、公司政策、已有承诺。
   - 对方有其他利益点你没看到。如公平感、尊严或面子。
2. 如果对方确实非理性，要么绕过他找别人谈，要么选择你的 BATNA。否则你会被拖入一个没有赢家的博弈。

### 7.2 应对不信任
1. 信任是多维度的：能力信任 vs 品格信任，要分别修复。不同原因需要不同解法。
2. 找到不信任的根源，针对性解决：
   - 缺乏能力 → 提供证据。
   - 缺乏诚信 → 做出补偿性让步，用行动证明。语言在失去信任后失效，只有行动能重建信任。

### 7.3 应对愤怒
1. 了解对方为什么愤怒，最好让对方直接说出来。发泄出来反而容易平息。
2. 让对方把愤怒说出来，不要压制。压制会升级为敌意。
3. 小心避开情绪问题，不要把对方的怒火揽到自己身上。如果你认为对方的攻击是针对你个人，你会失去冷静；理解这是情绪宣泄，你就能保持理性。
4. 帮助对方关注深层利益点，问“你现在想要什么样的结果？”愤怒时只关注情绪，引导他思考目标就能回到理性轨道。

### 7.4 应对威胁和最后通牒
1. 忽略威胁。假装没听到，继续谈别的内容，给对方台阶下。如果是虚张声势，忽略它会让对方失去效力；如果是真实的，他会再次强调。
2. 提前消除对方可能给出的威胁。先说出他的顾虑，让他无处发力。
3. 如果你确定威胁不存在，明确告诉对方，但要用正面尊重的方式。如“我相信我们的共同利益会让我们找到更好的解决方案”，而不是直接戳穿。

### 7.5 应对面子问题
1. 对方需要台阶才能改变立场，你必须帮他找到。人很难在公开场合承认错误或让步，有一个合理借口他就愿意接受。
2. 不要把自己的自我卷入谈判中。否则你会为了面子拒绝合理协议。
3. 不要轻易发誓“绝不让步”。否则以后你想让都让不了，誓言会锁死你的灵活性。


## 8. 谈判后：评估与复盘
### 8.1 评估谈判结果
1. 不要只看是否超过了自己的底线。底线只是最低可接受值，标准太低。
2. 要看在整个协议区间里你争取到了多少份额。份额越高说明越接近对方底线。
3. 更要看你当时掌握的信息下，你的策略是否合理。有些结果是运气，有些是策略，反思策略才能提高。
4. 如果后来发现新信息（如对方真实底线更高），要反推自己当初的假设哪里出了问题。错误假设是失败的根源，找到它才能改进。

### 8.2 判断什么时候不要谈判
以下情况中，谈判可能不是最佳选择：
1. 谈判成本大于可能收益时。你的时间和精力有限，投入产出不划算。
2. 你的 BATNA 极其糟糕，且对方也知道时。这时应先接受，再求助，而不是“谈判”。
3. 谈判会发出错误信号，让对方觉得你只在乎钱、不信任他。长期关系会受损。
4. 谈判会损害重要关系，而关系的价值大于这次能争取到的东西。
5. 文化禁忌不支持谈判时。违反文化规则会让你被排斥。
6. 你的 BATNA 已经比对方能给出的最好方案还要好时。直接走人。

### 8.3 协议后协议（PSS）
1. 签约后如果发现还有改进空间，可以提出重新讨论。签约后的氛围更放松，更容易接受新提议。
2. 关键：明确表示“只有对双方都更好时才生效，否则回到原协议”。对方不会担心你反悔，愿意配合尝试。


## 9. 通用心理学提醒
- **零和偏误**：默认一方所得=另一方所失 → 主动寻找互换和新增议题。
- 炫目偏误：被高调的数字/品牌吸引，忽略重要但不起眼的因素 → 用评分系统校准。
- 非理性投入升级：已投入太多不甘心退出，继续加码 → 提前设止损点，设“魔鬼代言人”。
- 表述陷阱：同样内容用“损失”还是“获得”表述，决策完全不同 → 换一种表述重估一次。
- 过度自信：过高估计自己的能力和胜算 → 用“局外人”视角重新审视。
- 自我中心主义：认为自己贡献更大、更占理 → 用“无知的面纱”反问自己。
- 后悔厌恶：怕事后后悔而坚持错误决定 → 关注决策过程是否正确，而非结果是否完美。
- 反应性贬值：仅仅因为是对方提出的方案就觉得它不好 → 把提案内容与提出者分开评估，只看内容本身的价值。
- 竞合思维：不要把对手在任何维度上都视为敌人。即使是对手，也可能在某些维度上合作。书中“竞合”概念提醒我们：谈判关系往往是混合动机的，既有竞争也有合作空间。
